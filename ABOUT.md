# 🌟 About Me

Hi there! I'm **Caroline Ngina**, a Data Engineer based in Nairobi, Kenya. I hold a BSc in Mathematics with a minor in Statistics, and I turn raw, messy data into clean, reliable datasets that people can use to make decisions.

## What I Do
- Design and build **ETL pipelines** and **data warehouses** using SQL Server (Bronze → Silver → Gold medallion architecture)
- Clean, transform and model data with **SQL** and **Python**
- Write data quality checks so the numbers can be trusted
- Document my work with data catalogs, naming conventions and architecture diagrams

## What Makes Me Different
My mathematics and statistics background means I don't just move data. I check that it makes sense. I care about accuracy, clear documentation and solutions that others can understand and reuse.

**[Data Warehouse Project using SQL](https://github.com/CarolineNgina/Data-Warehouse-project-using-SQL)**: an end-to-end warehouse integrating CRM and ERP data, with analytics-ready models for sales reporting.
